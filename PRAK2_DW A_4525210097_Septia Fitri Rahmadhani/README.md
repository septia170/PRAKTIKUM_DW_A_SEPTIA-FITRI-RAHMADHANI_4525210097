# Website Himpunan IMATIKA

## Deskripsi Proyek
Website ini dibuat untuk memperkenalkan Himpunan Mahasiswa Informatika (IMATIKA) serta memberikan informasi mengenai Fakultas Teknik Universitas Pancasila.

## Tujuan
- Memperkenalkan Himpunan IMATIKA.
- Menampilkan informasi Fakultas Teknik Universitas Pancasila.
- Menyediakan informasi keanggotaan dan kontak.

## Teknologi yang Digunakan
- HTML untuk menyusun struktur halaman website.
- CSS untuk mengatur tampilan dan tata letak website.

## Fitur Website
- Navigasi antarbagian halaman.
- Informasi Fakultas Teknik.
- Pengenalan Himpunan IMATIKA.
- Informasi keanggotaan.
- Informasi dan kontak.
- Tampilan responsif untuk perangkat berbeda.

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka file `index.html`.
3. Jalankan menggunakan browser untuk melihat tampilan website.
