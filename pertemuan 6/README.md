# Glow Beauty - Website Makeup

## Deskripsi
Glow Beauty adalah website bertema kecantikan yang menampilkan berbagai produk makeup. Website ini dibuat menggunakan HTML dan CSS dengan tampilan yang menarik, rapi, dan mudah digunakan.

## Tujuan
Tujuan pembuatan website ini adalah untuk menampilkan informasi produk makeup, kategori produk, serta promosi produk kecantikan melalui halaman website.

## Teknologi yang Digunakan
- HTML5 untuk membuat struktur halaman website.
- CSS3 untuk mengatur tampilan, warna, tata letak, dan desain website.

## Fitur Website
1. **Beranda** — Menampilkan halaman utama Glow Beauty.
2. **Kategori** — Menampilkan kategori produk makeup.
3. **Produk** — Menampilkan daftar produk makeup.
4. **Promo** — Menampilkan informasi promosi produk.
5. **Kontak** — Menampilkan informasi kontak Glow Beauty.

## Desain Website
- **Tema:** Beauty and Makeup
- **Nama website:** Glow Beauty
- **Warna utama:** Pink, rose, dan cream
- **Gaya desain:** Modern, minimalis, dan responsif
- **Layout:** Menggunakan header, navigasi, banner, kategori produk, daftar produk, promo, dan footer.

## Cara Menjalankan Website
1. Buka folder `Tugas_6_Glow_Beauty` di Visual Studio Code.
2. Pastikan file `index.html` dan `css/style.css` sudah tersedia.
3. Masukkan gambar produk ke folder `images`.
4. Buka file `index.html` menggunakan browser atau ekstensi Live Server di VS Code.

## Dokumentasi
Screenshot tampilan website dapat ditambahkan ke folder `dokumentasi` sebagai bukti hasil pengerjaan tugas.

## Penutup
Website Glow Beauty dibuat sebagai latihan pengembangan website menggunakan HTML dan CSS. Website ini diharapkan dapat menampilkan produk makeup dengan tampilan yang menarik, rapi, dan mudah dipahami oleh pengunjung.
