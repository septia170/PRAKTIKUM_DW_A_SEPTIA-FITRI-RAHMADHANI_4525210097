# SweetCup Café & Resto ♡

Website kafe dengan desain feminine pink aesthetic,
warna pastel, dan tampilan responsif.

## Fitur Website
- Beranda dan navigasi
- Menu kopi, minuman, dan dessert
- Filter kategori menu
- Keranjang pesanan sederhana
- Tentang kami
- Galeri foto kafe
- Informasi kontak
- Responsive design untuk desktop dan mobile

## Teknologi
- HTML
- CSS
- JavaScript

## Cara Menjalankan
1. Buka folder project di VS Code.
2. Buka file index.html.
3. Jalankan menggunakan ekstensi Live Server.

## Catatan
Foto dan font eksternal memerlukan koneksi internet.
Fitur keranjang masih berupa simulasi.
