# Tugas 03 — Modifikasi Profil Mahasiswa dengan CSS Inline

## Deskripsi

Tugas ini bertujuan memodifikasi halaman profil mahasiswa menggunakan CSS Inline tanpa membuat file CSS terpisah.

## Struktur Folder

```text
PRAK3_DW A_4525210097_Septia Fitri Rahmadhani/
├── README.md
├── Dokumentasi/
│   └── Images/
│       ├── desktop.png
│       └── mobile.png
└── css_inline/
    ├── Images/
    │   └── profil.jpeg
    └── index.html
```

## Perubahan yang Dilakukan

- Mengubah warna latar belakang dan teks.
- Mengatur ukuran serta ketebalan tulisan.
- Mengatur jarak menggunakan margin dan padding.
- Menambahkan border dan sudut membulat pada foto.
- Memperbarui tampilan bagian profil, keahlian, kontak, dan footer.
- Menggunakan format warna HEX, RGB, RGBA, dan nama warna.

## Dokumentasi

Folder `Dokumentasi/Images` digunakan untuk menyimpan screenshot sebelum dan sesudah perubahan serta hasil tampilan desktop dan mobile.

## Masalah dan Solusi

**Masalah:** Foto profil tidak muncul karena alamat atau nama file tidak sesuai.

**Solusi:** Memastikan file foto berada di folder `css_inline/Images` dan alamat gambar pada HTML sesuai.

## Kesimpulan

CSS Inline dapat digunakan untuk memperbarui tampilan halaman profil mahasiswa secara langsung melalui HTML tanpa file CSS terpisah.
