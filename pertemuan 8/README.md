# COURSELY - Form Pendaftaran Kursus

## Deskripsi
COURSELY merupakan website formulir pendaftaran kursus yang dibuat
menggunakan HTML, CSS, dan JavaScript.

Website ini digunakan untuk mengisi data calon peserta kursus
dan melakukan validasi sebelum formulir dikirim.

## Fitur
1. Input nama lengkap.
2. Input email.
3. Input nomor telepon.
4. Radio button jenis kelamin.
5. Select pilihan kursus.
6. Radio button jadwal kursus.
7. Checkbox metode pembelajaran.
8. Textarea alasan mengikuti kursus.
9. Upload bukti pembayaran.
10. Validasi input menggunakan JavaScript.
11. Tombol periksa, reset, dan daftar.

## Struktur Folder
- index.html
- css/style.css
- js/script.js
- dokumentasi/laporan_pengujian.md
- dokumentasi/screenshot/

## Cara Menjalankan
1. Buka folder COURSELY di Visual Studio Code.
2. Buka file index.html.
3. Klik kanan pada file tersebut.
4. Pilih Open with Live Server.

## Validasi
Validasi dilakukan untuk memastikan data yang dimasukkan
sesuai dengan ketentuan sebelum formulir diproses.

## Catatan
Project ini menggunakan validasi sisi klien (client-side).
Belum menggunakan backend atau database.
