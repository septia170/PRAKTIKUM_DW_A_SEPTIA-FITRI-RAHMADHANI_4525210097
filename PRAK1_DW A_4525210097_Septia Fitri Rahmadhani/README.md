## Deskripsi Project

Project ini merupakan tugas individu Praktikum Desain Web yang berisi halaman biodata mahasiswa menggunakan HTML. Halaman ini dibuat untuk menerapkan struktur dasar HTML dan menyusun informasi pribadi secara terstruktur.

## Tujuan Praktikum

Tujuan praktikum ini adalah memahami penggunaan elemen HTML, seperti heading, paragraf, teks tebal, teks miring, line break, dan HTML entity.

## Elemen HTML yang Digunakan

- `h1` untuk judul utama.
- `h2` dan `h3` untuk subjudul.
- `p` untuk membuat paragraf.
- `strong` untuk menebalkan teks.
- `em` untuk memberikan penekanan pada teks.
- `br` untuk membuat baris baru.
- `hr` untuk membuat garis pemisah.
- `small` untuk teks berukuran kecil.
- `&lt;`, `&gt;`, `&amp;`, dan `&copy;` sebagai HTML entity.

## Struktur File

- `index.html` berisi halaman biodata mahasiswa.
- `README.md` berisi dokumentasi project.
- `screenshot-desktop.png` berisi bukti tampilan desktop.
- `screenshot-mobile.png` berisi bukti tampilan mobile.
- `ringkasan.txt` berisi ringkasan perubahan, masalah, dan solusi.

## Cara Menjalankan

1. Buka folder project.
2. Buka file `index.html` menggunakan Google Chrome atau Microsoft Edge.
3. Halaman biodata akan ditampilkan di browser.

## Hasil Praktikum

Halaman biodata menampilkan identitas mahasiswa, minat dan hobi, tujuan belajar, serta harapan ke depan. Halaman dibuat menggunakan HTML tanpa framework tambahan.
