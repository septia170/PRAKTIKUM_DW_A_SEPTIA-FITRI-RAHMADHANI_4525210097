
# LAPORAN PENGUJIAN WEBSITE
## BEFORE YOU SAY I DO

### 1. Deskripsi Website

Before You Say I Do merupakan website edukasi yang membahas
tentang makna pernikahan, komitmen, tanggung jawab, dan persiapan
sebelum memasuki kehidupan pernikahan.

Website ini dibuat dengan tujuan memberikan informasi dan
meningkatkan kesadaran bahwa pernikahan membutuhkan kesiapan,
pemahaman, serta tanggung jawab dari kedua pihak.

### 2. Teknologi yang Digunakan

Teknologi yang digunakan dalam pembuatan website ini adalah:

1. HTML
   Digunakan untuk membuat struktur dan isi halaman website.

2. CSS
   Digunakan untuk mengatur warna, ukuran tulisan, tata letak,
   gambar, dan tampilan website.

3. JavaScript
   Digunakan untuk membuat menu navigasi interaktif dan
   melakukan validasi pada formulir pendaftaran.

### 3. Fitur Website

Beberapa fitur yang terdapat pada website ini adalah:

1. Halaman Beranda
   Menampilkan judul, slogan, dan gambar utama website.

2. Halaman Makna
   Menjelaskan arti dan pentingnya sebuah pernikahan.

3. Halaman Realita
   Menampilkan beberapa hal yang perlu dipahami dalam kehidupan
   pernikahan, seperti komunikasi, tanggung jawab, dan perbedaan.

4. Halaman Persiapan
   Memberikan informasi mengenai kesiapan emosional, finansial,
   komitmen, dan tujuan bersama.

5. Formulir Pendaftaran
   Digunakan sebagai simulasi pendaftaran kegiatan diskusi edukatif.

### 4. Pengujian Formulir

Pengujian dilakukan untuk mengetahui apakah setiap bagian
formulir dapat berjalan sesuai dengan fungsinya.

| No. | Pengujian | Hasil yang Diharapkan |
|-----|-----------|-----------------------|
| 1 | Nama kosong | Muncul pesan nama wajib diisi |
| 2 | Email kosong | Muncul pesan email wajib diisi |
| 3 | Format email salah | Muncul pesan format email tidak valid |
| 4 | Nomor telepon kosong | Muncul pesan nomor telepon wajib diisi |
| 5 | Kategori belum dipilih | Muncul pesan pilih kategori |
| 6 | Kehadiran belum dipilih | Muncul pesan pilih metode kehadiran |
| 7 | Topik belum dipilih | Muncul pesan pilih topik |
| 8 | Alasan kosong | Muncul pesan alasan wajib diisi |
| 9 | Format file salah | Muncul pesan format file tidak sesuai |
| 10 | Ukuran file lebih dari 2 MB | Muncul pesan ukuran file maksimal 2 MB |
| 11 | Persetujuan belum dicentang | Muncul pesan persetujuan |
| 12 | Semua data valid | Muncul pesan pendaftaran berhasil divalidasi |

### 5. Hasil Pengujian

Pengujian dilakukan secara langsung melalui browser dengan
memasukkan beberapa kondisi data pada formulir.

Hasil pengujian dapat diisi setelah setiap skenario dicoba.

| No. | Skenario | Hasil Aktual | Status |
|-----|----------|--------------|--------|
| 1 | Nama kosong | ................ | .... |

| 3 | Nomor telepon tidak valid | ................ | .... |
| 4 | Formulir diisi lengkap | ................ | .... |
| 5 | File tidak sesuai format | ................ | .... |

Keterangan:
- Berhasil: Fitur berjalan sesuai harapan.
- Gagal: Fitur belum berjalan sesuai harapan.

### 6. Kesimpulan

Berdasarkan pembuatan website Before You Say I Do, dapat
disimpulkan bahwa HTML, CSS, dan JavaScript dapat digunakan
untuk membuat website edukasi yang memiliki tampilan menarik
dan fitur interaktif.

Website ini juga dilengkapi dengan validasi formulir untuk
memeriksa data yang dimasukkan oleh pengguna.

Namun, formulir masih berupa simulasi front-end sehingga
belum terhubung dengan database atau server.
