
# Before You Say I Do

## Deskripsi Proyek

Before You Say I Do merupakan website edukasi yang membahas tentang
makna pernikahan, komitmen, tanggung jawab, dan persiapan sebelum
memasuki kehidupan pernikahan.

Website ini dibuat untuk memberikan pemahaman bahwa pernikahan
bukan hanya tentang acara atau pesta, tetapi juga tentang kesiapan
menjalani kehidupan bersama.

## Tujuan Website

1. Memberikan edukasi mengenai makna pernikahan.
2. Meningkatkan pemahaman tentang komitmen dan tanggung jawab.
3. Memberikan informasi mengenai persiapan sebelum menikah.
4. Menyediakan formulir pendaftaran kegiatan diskusi edukatif.

## Teknologi yang Digunakan

- HTML: Membuat struktur halaman website.
- CSS: Mengatur tampilan dan desain website.
- JavaScript: Mengatur interaksi dan validasi formulir.

## Struktur Folder

```text
Pertemuan 7/
├── index.html
├── style.css
├── script.js
├── README.md
├── Laporan_Pengujian.md
└── images/
```

## Cara Menjalankan Website

1. Buka folder proyek menggunakan Visual Studio Code.
2. Pastikan semua file berada dalam satu folder.
3. Buka file index.html.
4. Klik kanan dan pilih Open with Live Server.
5. Website akan terbuka melalui browser.

## Fitur Website

- Navigasi halaman.
- Informasi makna pernikahan.
- Informasi realita pernikahan.
- Daftar persiapan sebelum menikah.
- Formulir pendaftaran.
- Validasi input formulir.
- Tampilan responsif untuk perangkat HP.

## Catatan

Formulir pada website ini masih berupa simulasi front-end.
Data pendaftaran belum dikirim atau disimpan ke database.
